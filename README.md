# ltu-oracle-site

<img src="logo.svg" width="64" align="right" alt="">

Findings page of **ltu-oracle**: a nightly search over Lithuanian open data (Statistics
Lithuania, data.gov.lt, police, LHMT...) for series that tell in advance what other
series will do. Generated and pushed automatically after each night; no code here.
